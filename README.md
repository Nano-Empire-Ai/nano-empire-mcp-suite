# Nano Empire MCP Suite

Enterprise MCP servers for AI RFP teardown, codebase auditing, and A2A routing.

## Services
1. **MCP Readiness Audit**: Scans repositories for MCP wrapping readiness.
2. **AI RFP Teardown**: Extracts compliance matrices and AI-native advantages from RFPs.
3. **OmniForge A2A Router**: Routes tasks to the optimal agent in the mesh.

## Installation
```bash
pip install -e .
```

## Running
```bash
nano-mcp
```
